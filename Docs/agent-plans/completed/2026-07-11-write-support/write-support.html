Write support

Generated 2026-07-11

SwiftFITS is currently read-only: it parses existing FITS files into their header/data structure and round-trips them byte-for-byte, but cannot produce or alter files. This backlog collects the work needed to add write and serialization support to the library.

Backlog

  1. Allow creating, modifying and writing FITS files

    Extend SwiftFITS beyond read-only parsing so consumers can create new FITS files from scratch, modify the headers and data of parsed files, and serialize them back out to disk in a standards-compliant form.
